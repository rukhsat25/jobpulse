# JobPulse

A global tech job market intelligence lakehouse — ingesting job postings from
multiple free job-board APIs, processing them through a Bronze/Silver/Gold
Delta Lake pipeline with PySpark on Databricks, and serving business-ready
market analytics.

Status: 🚧 In development (Stage 5 — Databricks fundamentals complete)
